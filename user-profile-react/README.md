# User Profile Page

A simple React application that displays and allows editing of a user profile.

## Features
- View and edit user profile
- Save, undo, cancel edits
- localStorage persistence
- Birthday greeting
- Favorite color applied to buttons

## Notes / Assumptions
- Data is stored locally in the browser using localStorage (no backend).
- Birthdates are parsed as local dates to avoid timezone-related off-by-one issues.
- The project is implemented in JavaScript for simplicity, but can be migrated to TypeScript if needed.

## Project Structure
- src/App.jsx
- src/main.jsx

## Setup
npm install
npm run dev
